## CSSで動きを作る2つの方法

CSSで要素に動きを加えるには主に2つの方法があります：

| 方法 | 特徴 | 用途 |
|------|------|------|
| `transition` | 状態変化時のみ動く | ホバー・フォーカス・クリック |
| `animation` | 自動で繰り返せる | ローディング・装飾アニメーション |

## transition（トランジション）

プロパティが変化するときに、その変化を滑らかにします。

```css
.button {
  background: #3b82f6;
  transform: scale(1);
  /* プロパティ 時間 イージング 遅延 */
  transition: background 0.3s ease, transform 0.2s ease;
}

.button:hover {
  background: #2563eb;
  transform: scale(1.05);
}
```

### transitionのプロパティ

```css
.element {
  transition-property: opacity, transform; /* アニメーションするプロパティ */
  transition-duration: 0.3s;              /* 時間 */
  transition-timing-function: ease-in-out; /* イージング */
  transition-delay: 0.1s;                 /* 遅延 */

  /* 一括指定 */
  transition: all 0.3s ease;
  transition: opacity 0.3s ease, transform 0.5s ease-out;
}
```

### イージング関数

| 値 | 動き |
|----|------|
| `ease` | ゆっくり始まり、ゆっくり終わる（デフォルト） |
| `linear` | 一定速度 |
| `ease-in` | ゆっくり始まり、速く終わる |
| `ease-out` | 速く始まり、ゆっくり終わる |
| `ease-in-out` | ゆっくり始まり、ゆっくり終わる |
| `cubic-bezier(...)` | カスタムイージング |

## animation（アニメーション）

`@keyframes`でアニメーションの各ステップを定義します。

```css
/* @keyframesでアニメーションを定義 */
@keyframes fade-in {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

/* 要素に適用 */
.card {
  animation: fade-in 0.5s ease-out forwards;
}
```

### animationのプロパティ

```css
.element {
  animation-name: fade-in;           /* keyframes名 */
  animation-duration: 1s;            /* 1回の時間 */
  animation-timing-function: ease;   /* イージング */
  animation-delay: 0.2s;             /* 開始遅延 */
  animation-iteration-count: 3;      /* 繰り返し回数（infinite = 無限に */
  animation-direction: alternate;    /* 方向（alternate = 往復） */
  animation-fill-mode: forwards;     /* 終了後の状態 */
  animation-play-state: running;     /* 再生状態 */

  /* 一括指定 */
  animation: fade-in 1s ease-out 0.2s forwards;
}
```

## ローディングスピナー

```css
@keyframes spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}

.spinner {
  width: 40px;
  height: 40px;
  border: 4px solid #e5e7eb;
  border-top-color: #3b82f6;
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
}
```

## パルスアニメーション

```css
@keyframes pulse {
  0%, 100% { opacity: 1; }
  50%       { opacity: 0.4; }
}

.skeleton {
  animation: pulse 1.5s ease-in-out infinite;
}
```

<Callout type="warning" title="パフォーマンスに注意">
CSSアニメーションは`transform`と`opacity`のみを使うと、GPUでレンダリングされてパフォーマンスが良くなります。`width`・`height`・`top`・`left`などを変化させると、レイアウトの再計算（リフロー）が発生して重くなることがあります。
</Callout>

## prefers-reduced-motionへの対応

ユーザーがシステム設定でアニメーションを減らす設定をしている場合、それを尊重します：

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## まとめ

- `transition`は状態変化を滑らかにする（ホバーなど）
- `@keyframes`と`animation`で自動・繰り返しアニメーションを作る
- `transform`と`opacity`を使うとパフォーマンスが良い
- `prefers-reduced-motion`でアクセシビリティに配慮する
