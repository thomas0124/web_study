## 基本的なタグ

### 見出し（h1〜h6）

```html
<h1>最大の見出し（1ページに1つ）</h1>
<h2>セクション見出し</h2>
<h3>サブセクション見出し</h3>
```

h1〜h6の数字は**視覚的な大きさ**ではなく**論理的な階層**を表します。h1は1ページに1つが原則です。

### 段落・テキスト

```html
<p>これは段落です。ブロック要素なので前後に改行が入ります。</p>
<strong>重要なテキスト（太字・重要度）</strong>
<em>強調テキスト（斜体・強調）</em>
<br /> <!-- 改行 -->
```

### リスト

### リンク・画像

```html
<!-- リンク -->
<a href="https://example.com" target="_blank" rel="noopener noreferrer">
  外部サイトへ
</a>

<!-- 画像 -->
<img src="photo.jpg" alt="写真の説明" width="400" height="300" />
```

<Callout type="warning" title="altテキストは必須">
`<img>`の`alt`属性はスクリーンリーダーが読み上げるテキストです。省略するとアクセシビリティが損なわれ、SEOにも悪影響があります。必ず画像の内容を簡潔に説明するテキストを入れましょう。
</Callout>

## ブロック要素とインライン要素

HTMLの要素は2種類に分類されます：

**ブロック要素**: 前後に改行が入り、幅いっぱいに広がる  
例: `<div>`, `<p>`, `<h1>〜<h6>`, `<ul>`, `<table>`

**インライン要素**: 文章の流れの中に並ぶ  
例: `<span>`, `<a>`, `<img>`, `<strong>`, `<em>`

```html
<div>ブロック要素（前後に改行）</div>
<span>インライン要素</span>（テキストの中に並ぶ）
```

## HTMLの検証方法

書いたHTMLが正しいかどうかは [W3C Markup Validator](https://validator.w3.org/) で確認できます。

## まとめ

- HTMLはタグで囲んで意味と構造を付けるマークアップ言語
- `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>` が基本構造
- 見出し・段落・リスト・リンク・画像の基本タグを押さえる
- altテキストはアクセシビリティとSEOのために必須
