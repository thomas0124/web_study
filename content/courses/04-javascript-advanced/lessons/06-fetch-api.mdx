## Fetch APIとは

**Fetch API**はブラウザ内蔵のHTTP通信ライブラリです。`XMLHttpRequest`（古い方法）に代わる現代的なAPIで、Promiseベースで使いやすく設計されています。

## 基本的なGETリクエスト

```javascript
async function getUsers() {
  const response = await fetch("https://jsonplaceholder.typicode.com/users");

  if (!response.ok) {
    throw new Error(`HTTP error: ${response.status}`);
  }

  const users = await response.json();
  return users;
}
```

<Callout type="warning" title="fetchはネットワークエラーのみreject">
`fetch`はサーバーからレスポンスを受け取れた場合は、404や500でもrejectされません。`response.ok`（ステータスコード200-299）を必ず確認しましょう。
</Callout>

## レスポンスの処理

```javascript
const res = await fetch(url);

// ステータス確認
res.status;     // 200, 404, 500...
res.ok;         // 200-299はtrue
res.statusText; // "OK", "Not Found"...

// ヘッダー確認
res.headers.get("Content-Type");

// ボディを読み取る（1回のみ可能）
const json = await res.json();    // JSONとしてパース
const text = await res.text();    // テキストとして取得
const blob = await res.blob();    // Blob（ファイルなど）として取得
const buffer = await res.arrayBuffer(); // ArrayBufferとして取得
```

## POSTリクエスト（データ送信）

```javascript
async function createUser(userData) {
  const response = await fetch("/api/users", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "Authorization": `Bearer ${getToken()}`,
    },
    body: JSON.stringify(userData),
  });

  if (!response.ok) {
    const errorBody = await response.json();
    throw new Error(errorBody.message || "ユーザー作成失敗");
  }

  return response.json();
}

const newUser = await createUser({
  name: "田中太郎",
  email: "tanaka@example.com",
});
```

## RESTful APIとCRUD操作

```javascript
const API_BASE = "https://api.example.com";

// CREATE: 新規作成
async function createPost(data) {
  const res = await fetch(`${API_BASE}/posts`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(data),
  });
  return res.json();
}

// READ: 取得
async function getPost(id) {
  const res = await fetch(`${API_BASE}/posts/${id}`);
  if (!res.ok) throw new Error("Not found");
  return res.json();
}

// UPDATE: 更新
async function updatePost(id, data) {
  const res = await fetch(`${API_BASE}/posts/${id}`, {
    method: "PATCH",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(data),
  });
  return res.json();
}

// DELETE: 削除
async function deletePost(id) {
  const res = await fetch(`${API_BASE}/posts/${id}`, {
    method: "DELETE",
  });
  if (!res.ok) throw new Error("削除失敗");
}
```

## AbortControllerでキャンセル

```javascript
const controller = new AbortController();

// キャンセル可能なfetch
fetch("/api/large-data", { signal: controller.signal })
  .then(res => res.json())
  .catch(e => {
    if (e.name === "AbortError") {
      console.log("リクエストがキャンセルされました");
    }
  });

// 任意のタイミングでキャンセル
document.querySelector("#cancel-btn").addEventListener("click", () => {
  controller.abort();
});
```

## クエリパラメータの組み立て

```javascript
const params = new URLSearchParams({
  page: 1,
  limit: 10,
  sort: "createdAt",
  order: "desc",
});

fetch(`/api/posts?${params.toString()}`)
// → /api/posts?page=1&limit=10&sort=createdAt&order=desc
```

## フォームデータの送信

```javascript
const form = document.querySelector("form");

form.addEventListener("submit", async (e) => {
  e.preventDefault();

  const formData = new FormData(form);
  // ファイルアップロードも含む場合はformDataをそのまま送信
  const res = await fetch("/api/upload", {
    method: "POST",
    body: formData, // Content-TypeはFormDataが自動設定
  });

  const result = await res.json();
  console.log(result);
});
```

## まとめ

- `fetch(url, options)`でHTTPリクエストを送る
- `response.ok`でステータスコードを確認する
- JSONを送る場合は`Content-Type: application/json`と`JSON.stringify`が必要
- `AbortController`でリクエストをキャンセルできる
- `URLSearchParams`でクエリパラメータを安全に組み立てられる
