## 開発者ツールとは

**開発者ツール（DevTools）**は、ブラウザに内蔵された開発・デバッグ用のツールセットです。HTMLの構造確認・CSSの試し書き・JavaScriptのデバッグ・ネットワーク通信の確認など、Web開発に欠かせない機能が揃っています。

## 開発者ツールの開き方

| 方法 | 操作 |
|------|------|
| ショートカット | `F12` または `Cmd+Option+I`（Mac） |
| 右クリックメニュー | 「検証」または「Inspect」 |
| ブラウザメニュー | その他のツール → 開発者ツール |

## 主要なパネルの解説

### Elementsパネル（要素）

HTMLのDOM構造をリアルタイムで確認・編集できます。

**できること：**
- ページのHTML構造を確認する
- 特定の要素を選択してCSSプロパティを確認・編集する
- 一時的にコンテンツを変更してテストする

<Callout type="tip" title="要素の選択">
左上の矢印アイコン（またはCmd+Shift+C）をクリックしてページ上の要素をクリックすると、その要素がElementsパネルでハイライトされます。
</Callout>

### Consoleパネル（コンソール）

JavaScriptのエラーや`console.log()`の出力が表示されます。その場でJavaScriptを実行することもできます。

```javascript
// コンソールで実行できる
console.log("Hello, DevTools!");
document.title = "タイトル変更テスト";
```

**よく見るエラーメッセージ：**

| エラー | 原因 |
|--------|------|
| `Uncaught ReferenceError` | 存在しない変数を参照 |
| `TypeError: Cannot read properties of null` | null/undefinedへのアクセス |
| `404 Not Found` | リソースが見つからない |

### Networkパネル（ネットワーク）

ページが読み込むすべてのリソース（HTML・CSS・JS・画像・API）の通信状況を確認できます。

**確認できる情報：**
- リクエストのURL・メソッド・ステータスコード
- レスポンスタイム（何ms かかったか）
- レスポンスの内容（Headers・Preview・Response）
- ページ全体の読み込み時間

### Sourcesパネル（ソース）

JavaScriptのデバッグに使います。ブレークポイントを設定してコードの実行を一時停止し、変数の値を確認できます。

### Applicationパネル

- **LocalStorage・SessionStorage**: ブラウザに保存されたデータを確認・編集
- **Cookies**: Cookieの内容を確認・削除
- **Cache**: キャッシュされたリソースを確認

### Performanceパネル

ページの処理パフォーマンスを記録・分析できます。読み込み遅延の原因調査に使います。

## Lighthouseで品質チェック

DevToolsの**Lighthouseパネル**では、ページのパフォーマンス・アクセシビリティ・SEO・ベストプラクティスを自動で評価し、スコアと改善提案を出してくれます。

スコアの目安：
- 90以上: 優良
- 50〜89: 改善の余地あり
- 50未満: 要対応

## レスポンシブデザインのシミュレーション

DevToolsの**デバイスモード**（Cmd+Shift+M）を使うと、スマートフォンやタブレットの画面サイズをシミュレートできます。

## まとめ

- 開発者ツールはWeb開発に必須の組み込みツール
- Elementsでは構造・スタイルの確認と編集ができる
- Consoleではエラーの確認とJavaScriptの実行ができる
- Networkでは通信状況の詳細を把握できる
- Lighthouseでページの品質スコアを測定できる
