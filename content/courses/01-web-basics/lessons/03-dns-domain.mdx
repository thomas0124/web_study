## ドメイン名とIPアドレス

コンピューターはIPアドレス（例：`93.184.216.34`）で通信相手を特定しますが、人間には覚えにくいです。そこで**ドメイン名**（例：`example.com`）という人間が読める名前が使われます。

**DNS（Domain Name System）**は、ドメイン名をIPアドレスに変換する仕組みです。インターネットの「電話帳」と例えられます。

## ドメインの構造

ドメイン名は右から左へ階層構造になっています。

```
www.example.com
 │      │    │
 │      │    └── トップレベルドメイン（TLD）
 │      └──────── セカンドレベルドメイン
 └─────────────── サブドメイン
```

### トップレベルドメイン（TLD）の種類

| TLD | 用途 |
|-----|------|
| `.com` | 商業目的（最も一般的） |
| `.jp` | 日本の組織・個人 |
| `.org` | 非営利組織 |
| `.net` | ネットワーク関連 |
| `.co.jp` | 日本の企業 |
| `.gov` | 米国政府機関 |

## DNS解決の仕組み

`example.com`にアクセスするとき、裏側では次の手順でIPアドレスが調べられます。

```
1. ブラウザのキャッシュを確認
2. OSのキャッシュ（hostsファイル）を確認
3. リゾルバー（ISPのDNSサーバー）に問い合わせ
4. ルートDNSサーバーに問い合わせ
5. TLDネームサーバー（.com担当）に問い合わせ
6. 権威DNSサーバー（example.com担当）に問い合わせ
7. IPアドレス取得 → 接続
```

この一連の処理は通常**数十ミリ秒以内**に完了します。

<Callout type="note" title="DNSキャッシュの役割">
毎回すべての手順を踏むのは非効率なため、一度調べたドメインのIPアドレスは一定時間キャッシュ（保存）されます。キャッシュの有効期限はTTL（Time To Live）で管理されます。
</Callout>

## DNSレコードの種類

DNSには複数のレコードタイプがあり、それぞれ異なる情報を保持しています。

| レコード | 用途 | 例 |
|---------|------|-----|
| A | ドメイン → IPv4 | `example.com → 93.184.216.34` |
| AAAA | ドメイン → IPv6 | `example.com → 2606:2800:...` |
| CNAME | 別名（エイリアス） | `www → example.com` |
| MX | メールサーバー | メール受信先の指定 |
| TXT | テキスト情報 | ドメイン所有確認など |

## URLの完全な構造

URLはいくつかの要素で構成されています：

```
https://www.example.com:443/path/to/page?key=value#section
  │         │              │    │           │         │
  │         │              │    │           │         └── フラグメント
  │         │              │    │           └──────────── クエリパラメータ
  │         │              │    └──────────────────────── パス
  │         │              └───────────────────────────── ポート番号
  │         └──────────────────────────────────────────── ホスト（ドメイン）
  └────────────────────────────────────────────────────── スキーム（プロトコル）
```

## ドメインの取得

ドメインは**レジストラ（ドメイン登録事業者）**から購入・登録できます。代表的なサービス：
- お名前.com
- ムームードメイン
- Namecheap（海外）

年間数百円〜数千円で取得でき、独自のWebサイトやメールアドレスに使えます。

## まとめ

- DNSはドメイン名をIPアドレスに変換するシステム
- ドメインはTLD・セカンドレベル・サブドメインの階層構造
- DNS解決は複数のサーバーを経由して行われる
- DNSレコードにはA・CNAME・MXなど複数の種類がある
