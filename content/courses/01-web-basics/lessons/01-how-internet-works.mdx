## インターネットとは何か

インターネットとは、世界中のコンピューターを相互に接続した巨大なネットワークです。1960年代にアメリカ国防総省が研究目的で開発した「ARPANET」が起源とされており、現在では数十億台のデバイスが接続されています。

インターネットを「電話回線の世界版」と考えると分かりやすいです。電話が2台の端末を繋ぐのに対し、インターネットは世界中のあらゆる端末を相互に繋ぎます。

## パケット通信

インターネット上でデータを送受信する際、データは**パケット**と呼ばれる小さな単位に分割されます。

- 1つのファイルを複数のパケットに分割して送信する
- 各パケットは異なる経路を通って目的地に届く場合がある
- 受信側でパケットを元の順序に再組み立てる

この仕組みにより、一部の回線が切断されても別の経路でデータが届くため、信頼性が高まります。

```
送信元 → [パケット1] → ルーターA → ルーターC → 受信先
       → [パケット2] → ルーターB → ルーターC → 受信先
       → [パケット3] → ルーターA → ルーターC → 受信先
```

## IPアドレス

インターネット上の各デバイスには**IPアドレス**という固有の番号が割り当てられています。これは住所のようなもので、データの送り先を特定するために使われます。

現在は主に2つのバージョンが使われています：

| バージョン | 例 | 特徴 |
|----------|-----|------|
| IPv4 | 192.168.1.1 | 32ビット、約43億個 |
| IPv6 | 2001:db8::1 | 128ビット、事実上無限 |

IPv4のアドレスは枯渇が問題となっており、IPv6への移行が進んでいます。

## プロトコルの役割

プロトコルとは、コンピューター同士が通信するための**共通のルール**です。異なるメーカーや種類のコンピューターが問題なく通信できるのは、全員が同じプロトコルに従っているからです。

代表的なプロトコル：
- **IP（Internet Protocol）**: パケットの送受信ルール
- **TCP（Transmission Control Protocol）**: 信頼性の高いデータ転送
- **UDP（User Datagram Protocol）**: 速度優先のデータ転送（動画配信など）
- **HTTP/HTTPS**: Webページのデータ転送

## インターネットの構成要素

インターネットは以下の機器によって構成されています：

**ルーター**  
パケットの経路を決定する機器。郵便局の仕分けマシンのイメージです。

**スイッチ**  
同一ネットワーク内のデバイスを繋ぐ機器。家庭内のWi-Fiルーターも一種のスイッチです。

**サーバー**  
Webサイトのデータを保存・配信するコンピューター。24時間365日稼働しています。

<Callout type="tip" title="学習のポイント">
インターネットの仕組みを理解することは、後で学ぶHTTP・DNS・セキュリティの土台になります。難しく考えず「世界中のコンピューターが住所（IPアドレス）と共通のルール（プロトコル）で会話している」というイメージを持ちましょう。
</Callout>

## まとめ

- インターネットは世界中のコンピューターを繋ぐネットワーク
- データはパケットに分割して送受信される
- IPアドレスで送受信先を特定する
- プロトコルが共通のルールとして機能する
