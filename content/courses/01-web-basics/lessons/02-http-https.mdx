## HTTPとは

**HTTP（HyperText Transfer Protocol）**は、WebブラウザとWebサーバーがデータをやり取りするためのプロトコル（通信規則）です。あなたがURLを入力してページを開く瞬間、裏側ではHTTP通信が行われています。

## リクエストとレスポンス

HTTP通信は必ず**リクエスト（要求）**と**レスポンス（応答）**のペアで成り立ちます。

```
ブラウザ �� [リクエスト] → サーバー
ブラウザ ← [レスポンス] ← サーバー
```

### リクエストの構造

```
GET /index.html HTTP/1.1
Host: example.com
User-Agent: Mozilla/5.0
Accept: text/html
```

- **メソッド**: 何をしたいか（GET = 取得、POST = 送信など）
- **パス**: どのリソースが欲しいか（`/index.html`）
- **ヘッダー**: 追加情報（ブラウザの種類、受け入れるデータ形式など）

### レスポンスの構造

```
HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 1234

<!DOCTYPE html>
<html>...
```

- **ステータスコード**: 結果（200 = 成功、404 = 見つからない、500 = サーバーエラー）
- **ヘッダー**: レスポンスの詳細情報
- **ボディ**: 実際のデータ（HTMLなど）

## よく使うHTTPメソッド

| メソッド | 用途 | 例 |
|---------|------|-----|
| GET | データの取得 | ページの表示 |
| POST | データの送信・作成 | フォーム送信、新規投稿 |
| PUT | データの更新（全体） | プロフィール更新 |
| PATCH | データの更新（一部） | 名前だけ変更 |
| DELETE | データの削除 | 投稿の削除 |

## ステータスコードの分類

| 範囲 | 意味 | 代表例 |
|------|------|--------|
| 2xx | 成功 | 200 OK, 201 Created |
| 3xx | リダイレクト | 301 Moved Permanently, 302 Found |
| 4xx | クライアントエラー | 400 Bad Request, 403 Forbidden, 404 Not Found |
| 5xx | サーバーエラー | 500 Internal Server Error, 503 Service Unavailable |

<Callout type="info" title="404が有名な理由">
「404 Not Found」が広く知られているのは、URLのタイプミスや削除されたページにアクセスするとよく表示されるからです。「お探しのページは見つかりませんでした」という表示の裏では404ステータスコードが返っています。
</Callout>

## HTTPSとセキュリティ

**HTTPS**はHTTPに**TLS（Transport Layer Security）**による暗号化を加えたものです。

HTTPとHTTPSの違い：

| 項目 | HTTP | HTTPS |
|------|------|-------|
| 暗号化 | なし | あり（TLS） |
| ポート | 80 | 443 |
| アドレスバー | `http://` | `https://` + 鍵マーク |
| 個人情報の安全性 | 危険 | 安全 |

HTTPでは通信内容が第三者に盗み見られる可能性があります。パスワードやクレジットカード番号を送信するページには必ずHTTPSが必要です。現在では一般的なWebサイトもHTTPSが標準となっています。

## HTTP/2とHTTP/3

HTTPは進化し続けています：

- **HTTP/1.1**（1997年〜）: テキストベース、1リクエストずつ処理
- **HTTP/2**（2015年〜）: バイナリ形式、複数リクエストを並列処理
- **HTTP/3**（2022年〜）: UDP基盤、さらなる高速化

## まとめ

- HTTPはブラウザとサーバーの会話ルール
- リクエスト→レスポンスのペアで通信する
- ステータスコードで結果を把握できる
- HTTPSは暗号化により通信を保護する
